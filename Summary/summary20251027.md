## Rust WASM Hello World Project

### Installed Rust toolchain
- Installed Rust using rustup (version 1.90.0)
- Configured cargo environment

### Installed wasm-pack
- Installed wasm-pack v0.13.1 using cargo
- This tool compiles Rust to WebAssembly

### Created hello-wasm library
- Initialized new Rust library project: `hello-wasm`
- Configured Cargo.toml with:
  - `crate-type = ["cdylib"]` for dynamic library
  - `wasm-bindgen = "0.2"` dependency for JS interop

### Implemented functions
- `greet(name: &str) -> String`: Returns greeting message
- `add(a: i32, b: i32) -> i32`: Adds two numbers
- Both functions exported via `#[wasm_bindgen]` attribute

### Built WASM module
- Ran `wasm-pack build --target web`
- Generated files in `pkg/` directory:
  - `hello_wasm_bg.wasm`: compiled WebAssembly
  - `hello_wasm.js`: JavaScript bindings
  - TypeScript definitions

### Created web interface
- Built `index.html` with interactive UI
- Implemented ES6 module import for WASM
- Added forms to test both greet and add functions
- Styled with CSS for clean presentation

### Testing the project

To test the WASM application in the browser:

```bash
cd hello-wasm
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

Note: A local web server is required due to CORS restrictions when loading ES6 modules.

### Rebuilding after changes

To rebuild the WASM module after modifying Rust code:

```bash
cd hello-wasm
. "$HOME/.cargo/env"
wasm-pack build --target web
```
